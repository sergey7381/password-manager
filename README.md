# Password Manager

A simple password manager built with Python.

## Features

- Add passwords
- View saved password names
- View a saved password by selecting its number
- Clear all saved passwords
- Basic input error handling
- Stores passwords in a local `.txt` file

## Security Disclaimer

This is an educational project and should not be used to store real passwords or other sensitive information.

Passwords are stored in a plain `.txt` file and are not encrypted. Anyone who gains access to the file may be able to read the stored passwords.

## Technologies

- Python
- File handling
- Functions
- Loops
- Conditions
- Error handling
